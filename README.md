# Hellenstar V9 — Audio Lab

V9 development branch: `v9-development`.

## What's new in V9
- Local audio workspace with pitch and output level controls.
- Optional Android audio-session effects: bass boost and virtualizer, where supported by the device.
- Low, balanced, and bright test-tone profiles.
- Save/load a local profile using on-device preferences.
- Owner console with PBKDF2-SHA256 password verification, change-password control, and a five-attempt per-session limit.
- Device/build diagnostics with copy-to-clipboard.
- Admin controls that actually affect the normal app: allow/disable test tone, enable/disable device effects, and show/hide advanced profiles.
- Recent admin activity log and app-control reset that does not reset the password.
- No Discord token collection, microphone permission, internet permission, or background service in this prototype.

## Owner access
Use the owner password provided separately in the development conversation, then change it immediately from the admin panel. Do not reuse passwords from other accounts.

The panel is a local app-level lock. It is not server-enforced identity security; anyone who can modify the APK can bypass it. Real owner-only access across devices would require a backend with proper authentication.

## Important limitation
This is still a clean prototype, not a source-level modification of the original XenoCord V5 APK. The original source project was not provided. These audio controls affect audio generated by this app only; Android does not let an ordinary app automatically process Discord's microphone or output stream.

## Build
A push to `v9-development` triggers the Android debug build. Open the repository's Actions tab and download the `hellenstar-v9-debug-apk` artifact after a successful run.
