# Hellenstar — Android Audio Lab (V9 development)

V9 is being developed on the `v9-development` branch. It builds on the local audio lab with a private, password-gated owner console and extra local controls.

## Current features
- Dark Hellenstar audio lab UI
- Local test tone with adjustable pitch and output level
- Optional Android audio-session effects: bass boost and virtualizer
- Owner-only in-app admin console with device/build diagnostics
- Admin preferences for diagnostics, experimental UI, and verbose status
- Changeable owner password and local preferences reset
- No Discord credentials, internet permission, microphone permission, or background service

## Important limitations
The audio controls apply to audio generated by this app only. They do not automatically process Discord's microphone or output.

The admin panel is an offline, app-level gate, not server-enforced security. A person with the APK and reverse-engineering skills could inspect or modify it. The default password should be changed after first login. Do not reuse a password used for other accounts.

This remains a clean prototype, not a source-level modification of the original V5 APK; its original source project was not provided.

## Build
The GitHub Actions workflow builds a debug APK on pushes to this branch. Open the repository's Actions tab and download the `hellenstar-v9-debug-apk` artifact from a successful run.
