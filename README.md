# Hellenstar — Android Audio Lab (V8)

Hellenstar is a clean Android audio-control prototype. It is not a modified Discord client and never asks for Discord credentials.

## Features
- Dark Hellenstar interface
- Local test tone with adjustable pitch and output level
- Optional Android audio-session effects: bass boost and virtualizer
- Graceful handling of unsupported device effects
- No network, microphone, or background-service permissions
- Automated debug APK build through GitHub Actions

## Limitations
Audio effects apply to audio generated by this app only. They do not automatically process Discord's microphone or output. Ordinary Android apps cannot reliably inject effects into another app's audio stream without a supported system-level route.

This is a clean prototype, not a source-level modification of the original V5 APK; the original source project was not provided.

## Build
Use JDK 17, Android SDK platform 35, and Gradle 8.9:
```bash
gradle assembleDebug
```
APK output: `app/build/outputs/apk/debug/app-debug.apk`.

## Privacy
- No Discord token or password fields
- No internet or microphone permission
- No analytics, ads, or background service
- No guarantee of zero bugs; test on the target device before relying on it
